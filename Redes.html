01. Redes

La Organización de Computadoras estudia los componentes físicos del sistema (hardware) y la manera en que se interconectan para ejecutar instrucciones mediante el modelo Von Neumann.

Los elementos clave son la CPU (procesador), la memoria RAM (almacenamiento temporal) y los periféricos de Entrada y Salida.

Cuestionario de Autoevaluación

Responde las preguntas y presiona el botón al final para validar tus conocimientos.

1. ¿Qué protocolo o dirección identifica de forma única a un dispositivo conectado a una red?
2. En una red hogareña, ¿qué dispositivo distribuye la señal de internet (por cable o Wi-Fi)?
3. ¿Qué tipo de red cubre un área geográfica pequeña, como una casa, escuela o una oficina?
